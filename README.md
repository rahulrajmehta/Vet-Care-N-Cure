## ✨ Features

- **Centered Typography Hierarchy:** All section titles, badges, and headers follow a clean, centered layout.
- **HTML5 Looping Pet Video Background:** Video background in the hero banner with audio and play toggles.
- **Dual Direct Conversion Modals:**
  - **Doctor Consultation Booking:** Pre-fills pet parent details, pet breed, appointment slot, and generates an automated WhatsApp booking text.
  - **Doorstep Delivery Ordering:** Area selector for Jamshedpur (Baridih, Telco, Sakchi, Bistupur, Golmuri, Kadma, Sonari, Mango) for pet food and prescription medicine delivery.
- **Local SEO Optimized:**
  - JSON-LD Structured Data for `VeterinaryCare`, `PetStore`, and `LocalBusiness`.
  - Geo tags for Jamshedpur (`geo.position: 22.7938;86.2415`, `geo.region: IN-JH`).
  - Google FAQ Schema accordion.
  - Google Maps directions embed and Plus Code copy functionality.
- **Interactive Visit Cost Estimator:** Real-time price calculator for consultation, vaccination, and grooming.
- **Mobile-First Experience:** Persistent sticky bottom bar on mobile screens with quick access to call, order, and book.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla JavaScript:** Lightning-fast, zero framework dependencies.
- **Tailwind CSS & Custom Design System:** Luxury emerald teal (`#064E3B`) and royal amber gold (`#D97706`).
- **Font Awesome 6 & Google Fonts:** Outfit & Plus Jakarta Sans.
- **Node.js Static Server:** With byte-range streaming support for videos.

## 🚀 Getting Started

To run locally:
```bash
# Clone the repository
git clone https://github.com/rahulrajmehta/Vet-Care-N-Cure.git

# Navigate to project directory
cd Vet-Care-N-Cure

# Start local server
node server.js
```
Open [http://localhost:8080](http://localhost:8080) in your browser.
